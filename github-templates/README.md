# GitHub templates (to be moved)

These are the issue and pull request templates for this repository. GitHub only uses them when they live in a folder named `.github` at the root of the repository.

**Maintainer, one-time step:** rename this folder from `github-templates` to `.github` (in Finder, confirm "Use ." when macOS warns about names starting with a dot; the folder will then be hidden in Finder, which is normal), delete this README, and commit.
