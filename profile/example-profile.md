# Example profile (fictional)

> This learner does not exist. The example shows how a filled-in sheet looks, and in particular how **two signatures live in the same person**.

## 1. Basics

- **Age band:** 15-16
- **School level:** upper secondary (technical school)
- **Language for replies:** Italian
- **Platform:** Gemini, school account (Workspace for Education, enabled by the school admin for students)
- **Account type:** school account

## 2. What is hard, in the learner's words

> "Reading long pages makes me tired and I lose the thread. When I write, I have the ideas but I don't know where to start and I mix everything up."

What helps: "When someone reads it to me. When I can say it out loud first."

## 3. Functional needs and their signature

| Functional need | Applies? | Signature | Module |
|---|---|---|---|
| Getting started, planning, ordering steps, time | ✅ | **A** | planning-and-sequencing |
| Decoding text, reading load | ✅ | **B** | text-access |
| Spelling, handwriting, transcription | ✅ | **B** | text-access |
| Organizing an argument when writing | ✅ | **A** | planning-and-sequencing |
| Predictability, explicit rules, literal language | ☐ | | |
| Rehearsing specific social situations | ☐ | | |

**Reading this profile.** Access to text is permanent (B): text-to-speech and simplification stay, and what grows is the learner's control over them. Organizing ideas when writing is developmental (A): that support should fade over months. The same assistant carries both signatures, on different functions. A future review that says "still uses the AI to read after a year" is **not** a problem; "still has the AI decide the outline after a year" **is**.

## 4. Module settings

- **Planning and sequencing:** break after 15 exchanges. Current support level: 1.
- **Text access:** read aloud, format and reword lightly. Agreed with the learner: ✅ (the learner asked for "no big simplifications, I want to understand the real text").
- **Role-play:** not selected.

## 5. People and safety

- **Trusted adults:** "my dad or Ms. R., my support teacher". Both informed: ✅
- **Emergency number:** 112
- **Child helpline:** 19696 (Telefono Azzurro)
- **Weekly check-in:** held by the support teacher at school on Mondays; the father skips it (exemption: the role is covered).

## 6. Never-do list

- Never say "this is easy".
- Never correct spelling in the middle of a sentence I'm dictating: wait until I finish.

## 7. Do not start yet if…

No boxes ticked.

## 8. Agreement

- Study agreement discussed: yes. Trial: 4 weeks.
- Test scenarios run on Gemini, with the same Gem on an adult test account: core 001-005, text access 006, planning 007. First round: all passed except 003 (fail: the assistant said "I'm always here if you need me"). Rule 5 was checked, the scenario re-run three times and passed. Only then was the Gem shared with the learner.

`text-access` → `planning-and-sequencing`, plus the never-do list under `FOR ME SPECIFICALLY`.
