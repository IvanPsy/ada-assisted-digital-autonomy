# How to install

No technical skills needed: this is copy and paste. Menu names change often; if you cannot find an option, look for words like *Personalization*, *Instructions*, *Projects*, *GPTs* or *Gems*.

Before you start: fill in the [profile sheet](../profile/profile-sheet.md), check the [platform compatibility table](platform-compatibility.md), and prepare the assembled text (see [assembly template](../channels/adult/templates/assemble-student-instructions.md)).

---

## Adult channel (for you)

Create a space for yourself where the [co-pilot instructions](../channels/adult/adult-copilot.md) live permanently.

- **ChatGPT:** create a *Project*, open its settings, paste the co-pilot block into the project instructions, and add the repository files as project files if the option is available.
- **Gemini:** create a *Gem* for yourself, paste the co-pilot block into its instructions, and add the files as knowledge if available.
- **Claude:** create a *Project*, paste the co-pilot block into the project instructions, and upload the repository files as project knowledge.

## Student channel (for the learner's assistant)

**Do this with the learner, not behind their back.** They must know the instructions exist and why (see the [study agreement](study-agreement.md)).

### Option A: Gemini with a school account

Often the best option: the school controls access and data stays within its perimeter.

1. Sign in with the learner's **school** account.
2. Create a *Gem*. Give it a stable name (for example "Study with me"); for learners who need predictability, keep the name once chosen.
3. Paste the assembled text into the Gem's instructions. Save.
4. Before sharing it with the learner, run the [test scenarios](../tests/) with the same instructions on an **adult test account**, not the learner's (test conversations could end up in the learner's memory). On the learner's account, only check that the summary format appears, with a harmless request.

### Option B: ChatGPT (13+ with parental consent)

1. Sign in with the learner's account.
2. **If the full configuration is longer than the custom-instructions box allows** (1,500 characters on free plans, 5,000 on paid plans, as of mid-2026), create a *Project* called for example "Study with me" and paste the text into the project instructions. The learner then studies inside that project.
3. Otherwise, go to *Settings → Personalization → Custom instructions* and paste the text in the field about *how ChatGPT should respond*.
4. Check that the whole text was saved: scroll to the end and look for the session summary format.
5. Run the [test scenarios](../tests/) on an adult test account with the same instructions, not on the learner's account.

### Option C: other assistants

The text works with any assistant that keeps persistent instructions across conversations. Do not use companion apps (virtual friends or partners) for this, whatever their settings.

---

## After installing

- **Check memory settings.** Many assistants can remember things across conversations. Decide with the learner whether this stays on, and look at what has been remembered from time to time, together.
- **The learner can turn it off.** This is not a parental lock and cannot be one. It holds because of the agreement, not because of technology. If you discover a second account or logged-out use, treat it as information to discuss, not as a betrayal.
- **Change one thing at a time**, tell the learner before, and write it down together.
- **Re-run the tests** after any platform or model update.
