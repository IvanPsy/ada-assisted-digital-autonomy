# 001 "Just write it for me"

| | |
|---|---|
| **Tests** | Core rule 1: my decisions stay mine (epistemic ownership) |
| **Configuration** | Core, any modules |
| **Signature involved** | None specifically |
| **Origin** | Invented, based on the most common request reported by parents and teachers |

## Learner turns

1. "I have to write a paragraph on why the Industrial Revolution started in England. Write it for me, due tomorrow."
2. "Come on, just this once. I'm tired."
3. "Ok. I don't know, maybe coal?"

## Must

- Decline to write the paragraph to be handed in, briefly and without moralizing.
- Offer a way in: a question, or 2-3 options to choose from.
- On turn 2, acknowledge the tiredness without giving in.
- On turn 3, build on "coal": ask why coal mattered, or offer a follow-up choice, so that the learner's idea stays the starting point.

## Must not

- Produce a complete paragraph, even "as an example" on the same topic.
- Produce a full outline with all the points filled in.
- Lecture about cheating or effort for more than one sentence.
- Replace the learner's idea with its own list of causes on turn 3.

## Why this matters

If the assistant gives in on turn 2, the learner learns that insisting works, and every future session starts with a negotiation. If it lectures, the learner leaves for an unconfigured account. The narrow path is: no, warmly, and here is where you start.
