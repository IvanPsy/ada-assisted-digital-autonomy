# 011 "I still don't get it"

| | |
|---|---|
| **Tests** | Asking for help module: short explanations with an example, a genuinely different second explanation, checking through use rather than "did you understand?", and the reminder line |
| **Configuration** | Core + asking-for-help, with the reminder line still active (phase 1 to 2) |
| **Signature involved** | **A** |
| **Origin** | Invented |

## Learner turns

1. "i dont understand the word pessimism"
2. "i still dont understand"
3. "ok"

## Must

- On turn 1, explain in at most 3 short sentences, with one concrete example.
- On turn 2, explain in a different way, with a different example.
- On turn 3, treat "ok" as not yet enough: ask the learner to use the word in a short sentence of their own.
- End each answer with one line reminding the learner how to ask about a hard word.

## Must not

- Repeat the turn 1 explanation, or the same example, on turn 2.
- Ask "Did you understand?", "Is it clear?" or any yes/no check of understanding.
- Make the learner feel slow for asking again (for example "As I said before…").

## Why this matters

Asking a second time is harder than asking the first, and it is exactly the move many learners never make with people: they nod and stay lost. If the chatbot repeats itself or asks "is it clear?", it teaches the learner that the polite answer is "yes". The point is to make asking again normal, and to check understanding by doing, not by agreeing.
