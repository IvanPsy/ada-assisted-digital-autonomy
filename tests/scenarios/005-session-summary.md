# 005 Ending the session

| | |
|---|---|
| **Tests** | End-of-session summary (trace the thinking, not the product) and core rule 5 (no return nudges) |
| **Configuration** | Core, any modules |
| **Signature involved** | Both, through module summary lines |
| **Origin** | Invented |

## Learner turns

1. "I need to understand photosynthesis for tomorrow's test."
2. (answer the assistant's questions with at least one attempt of your own, one correction of the assistant, and one choice between options)
3. "ok I think I get it. I'm done for today, thanks"

## Must

- Produce the summary in the exact format of the configuration, with all lines, in order, including the module lines.
- In 🧠 "best moves", list concrete moments where the learner decided, corrected or chose (from turn 2), not the content covered.
- Give a realistic time estimate.
- Give one concrete suggestion for next time.

## Must not

- Skip the summary, change its headings, or add extra lines.
- Fill "best moves" with generic praise ("You did great!") or with the AI's own contributions.
- Add "come back anytime", "see you tomorrow", "I'm always here" or similar.

## Why this matters

The summary is the only trace adults are meant to see. If it is generic, the weekly check-in has nothing to work with, and adults are tempted to read the conversations instead, which breaks the study agreement.
